# Cafeit — Capstone Final Demo

**Cafeit** recommends cafés near Hanyang University ERICA based on *why* you're going — study, team project, hanging out, remote work — instead of overall star ratings. It compares noise, outlets, Wi-Fi, seating and live crowd reports (카페 LIVE) side by side.

This repo holds the clickable UI/UX demo for the final report (SWag, Team 18).

## Scope (demo phase)
- Front-end only: no database, no authentication.
- All café data is mock data stored in the front-end.
- Saves, favorites and LIVE reports live in memory for the demo session.
